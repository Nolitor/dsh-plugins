v0.2.4 translates the first-run onboarding screen that shipped with DSH `0.2.2-alpha.2`: all **39 `settings.account.onboarding*` strings** (welcome, purpose, detail level, credits, and skip prompts) now render in Korean instead of falling back to English. Six loading messages also use the ellipsis character (`…`) instead of three dots.

Verified against the installed DSH `0.2.2-alpha.2` runtime: **68 dictionaries / 3,019 keys**, 0 missing, 0 extra, 0 placeholder mismatches. Repository, package, and documentation URLs now point at `Nolitor/dsh-korean-locale`.

**Install:** `dsh plugin --profile web add @nolit/dsh-korean-locale`
**Verify:** `node scripts/verify.mjs` → metadata, apply contract, typography, and stand-down guard pass.

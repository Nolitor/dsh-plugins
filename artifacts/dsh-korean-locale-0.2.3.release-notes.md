v0.2.3 refreshes the Korean dictionary snapshot for DSH `0.2.2-alpha.2` — **68 namespaces / 3,019 strings** (117 keys added, 8 retired keys removed), drops a duplicate `%` from the context tooltip, and keeps the scoped Pretendard typography. `engines.dsh` is verified as `>=0.2.2-alpha.2 <0.3.0`.

English `README.md` is the default document; `README.ko.md` is its reciprocal Korean translation. `CHANGELOG.md` and `CHANGELOG.ko.md` record the version history.

**Install:** `dsh plugin --profile web add @nolit/dsh-korean-locale`
**Verify:** `node scripts/verify.mjs` → 68 namespaces / 3,019 keys; metadata, apply contract, typography, and stand-down guard pass.

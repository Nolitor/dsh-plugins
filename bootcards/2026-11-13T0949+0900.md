## 1. Non-negotiable rules

1. **Measure first.** Read actual state; do not trust memory, report text, or a plan.
2. **Sidebar Manager drift gate.** The live plugin may include UTM modifications that differ from
   the packaged release. Before any change/version-up: run `node scripts/audit-installed-vs-packaged.mjs`,
   record tree SHA-256, test the current behavior in an isolated `DSH_HOME`, then version-up.
3. **Isolate live state.** Use a workspace-local `DSH_HOME` for experiments. Do not write
   `~/.dsh`, the live profile, sessions, or the running 3080 service without explicit approval.
4. **Version gate.** Plugin `engines.dsh` must include the running DSH prerelease exactly:
   `>=0.2.2-alpha.2 <0.3.0` for the current generation.
5. **Release artifacts are immutable.** Update `artifacts/SHA256SUMS.*` whenever a package
   changes; never claim a release without a matching hash.
6. **UTM is advisory.** Do not introduce hard write-blocks based on UTM role/policy. Use
   observation, warning, soft rejection, and audit records only.
7. **Notification delivery is deduped.** If Chrome OS notification succeeds, do not also show
   the in-app toast; use toast/title/sound only as fallback.
8. **Locale parity.** Korean dictionaries must match both `en` and `zh` key sets and
   placeholders before release.
9. **Single writer.** Write only inside your assigned `dsh-<track>/`. Never write a sibling
   track via a bare relative path; assert `package.json.name` before replacing a manifest.
10. **Plugin replacement is 4 steps, never one.** disable incumbent row -> remove incumbent
   package -> add new package -> verify by **real mount**. A passing `--dump-config` does NOT
   prove a plugin mounts; two plugins registering the same tool/route is a hard mount failure.

**What shipped.** The model-serving list had **no refresh logic at all** (one mount-time load, no
subscription, no timer, no button). The owner ordered three structures, all delivered:

1. **Backend `?refresh=1`** drops each vendor's own cache (antigravity `catalog.invalidate()`,
   deepinfra `invalidateCatalog()`, opencode `catalog.refresh()`). A malformed URL is a plain read;
   a failed probe still answers 200.
2. **A refresh button on both surfaces** — models-tab toolbar and dashboard header. The header
   button had been **throwing** (`setReload(read)` passed `read` as a React updater, so `reload`
   became `undefined`).
3. **One refresh bus** (`onRefresh`/`requestRefresh`): buttons send `{force:true}`, host events
   send `{force:false}`, so an event never spends an upstream request. `remote` is now a declared
   inject.

**Six defects fixed, each with a regression test** — full detail in
[../dsh-custom-router/docs/MODEL-LIST-REFRESH.md](../dsh-custom-router/docs/MODEL-LIST-REFRESH.md):

| # | Defect | Evidence |
|---|---|---|
| 1 | Catalog fetched from `cloudcode-pa` (26 models, no Hydrogen) instead of `daily-cloudcode-pa` (31, 4 Hydrogen) | `rpc()` hardcoded the control host, ignoring `baseUrl` |
| 2 | `splitEffort` knew only `low/medium/high` | `gemini-4-hydrogen-xhigh` became its own base row |
| 3 | `EFFORT_ORDER`/`EFFORT_NAMES`/name-trim knew 3 levels | `indexOf('xhigh') === -1` sorted it ahead of `low`; row kept `(XHigh)` in its name |
| 4 | **F-40**: `modelForEffort()` folded `xhigh → high` unconditionally | selecting XHigh sent High |
| 5 | DeepInfra promo badge: `Number(null) === 0` is finite | all 83 full-price rows badged `0%`; live now **8 discounted / 83 list** |
| 6 | `-disabled` routes offered as selectable models | `gemini-4-carbon-disabled` has a displayName but no quota |

Plus a pre-existing test-isolation leak: `vendor/opencode` read the operator's **live** catalog
because `adapterFor()`/`makeAdapter()` omitted `catalogPath` (6–8 failures on a developer machine,
green in CI). Now isolated.

**Owner already exercised the fix** (measured in the live patch): antigravity `enabledModels` = 13

## 4. Rules this round earned (read before touching the router)

**R1 — A "verified" claim must name HOW it was verified.** This round's worst process failure: the
`?refresh=1` bypass was called verified on **fixture** tests. A stub catalog cannot prove that a
network fetch, a daemon probe or a durable cache file was re-read. Say "fixture-verified" or run
`npm run verify:refresh` (real routes, isolated home). The owner caught this.

**R2 — Read the contract document before changing a mapping.** The owner's sharper correction: adding
`xhigh` to a regex was not the fix; **F-40** in [../docs/FAILURE-LEDGER.md](../docs/FAILURE-LEDGER.md)
already specified "group the ids, expose the efforts, **and reverse the mapping on the way out**".
The reverse half was broken (`xhigh → high`). Check the forward function *and its pair*, then write a
round-trip test.

**R3 — Two cloudcode hosts are not interchangeable.** `daily-cloudcode-pa.googleapis.com` serves 31
models with 4 Hydrogen; `cloudcode-pa.googleapis.com` serves 26 with none. The catalog comes from the
**daily** host. `loadCodeAssist` answers on both. Card, README and code now agree; an earlier README
table said otherwise and the code was written from it.

**R4 — Presence in the tab ≠ presence in the prompt.** `catalog.all()` ignores `enabledModels`;
`catalog.list()` (what the prompt picker reads) filters. A model can be listed and unselectable until
saved. For OpenCode there is a further **plan** gate: `opencode/gemini-4-hydrogen` is Zen, and the
profile runs `activePlan: go`.

**R5 — Adding a preset touches FIVE places, two silently.** `lib/presets.js`, the browser
`MODEL_PRESETS`, `fetchUsageFeeds` (a literal 3-vendor array), the expected-id array in
`test/inventory-metadata.test.mjs:151`, and the locale tables. Forgetting the middle two renders **no
tab and no usage card with no error**. Audit + 6-step plan:
[../dsh-custom-router/docs/PRESET-REGISTRY-STANDARD.md](../dsh-custom-router/docs/PRESET-REGISTRY-STANDARD.md).
**Not implemented** (owner chose to record only).

**R6 — `npm test` does not run the vendor suites.** It runs `test/*.test.mjs` only. A green router
suite says nothing about antigravity/deepinfra/opencode; run those three separately.

**R7 — A test that reads `$DSH_HOME` is not a test.** Two helpers omitted `catalogPath`, so the
suite read the operator's live `opencode-models.json` and passed in CI while failing locally.
`node scripts/check-dsh-isolation.mjs` only inspects `dsh` **launchers**, so it does not catch this.

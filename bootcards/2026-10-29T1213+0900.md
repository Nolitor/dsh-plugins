## 4. Current policies and known deltas

- **Two LLM routes, one package.** `opencode-agent` = *OpenCode v2 (CLI)*, a CLI child per
  generation (stdin prompt, fallback/default). `opencode-http-agent` = *OpenCode v2 (HTTP)*, the
  OpenCode v2 HTTP API (persistent session per DSH `sessionId`, SSE deltas, inline usage,
  permission bridge, interrupt). Both advertise **the same model set** — the routes the serving
  OpenCode server exposes in `GET /api/model` (46 entries incl. the `default` pseudo-route); they
  differ only in transport. Never mount both a `@quonaro/dsh-plugin-opencode` bundle and
  `@nolit/dsh-opencode-v2` in one profile: duplicate `opencode` tool / `opencode-agent` adapter →
  two entries do not activate.
- **The OpenCode daemon is not a service.** `opencode serve --service` is spawned on demand by
  the CLI and dies with the process that spawned it, so a freshly booted host usually has **no**
  daemon to attach to. The HTTP route therefore verifies the endpoint (`/api/info`), falls back
  to spawning its own `opencode serve --port 0`, and retries once if an attached daemon vanishes.
- **`opencodePath` must be absolute** in a profile whose host PATH lacks the OpenCode install:
  `dsh-web.service` exports `PATH=/home/minami/.local/nodejs/bin:/home/minami/.local/bin:$PATH`
  (no `~/.bun/bin`); the binary is `/home/minami/.bun/bin/opencode`. Without it the spawn
  fallback cannot start and the route ends up with no models (measured symptom on 2026-10-29).
- **An empty model list is never silent.** `listModels` throws with the concrete reason, so the
  host renders a provider failure instead of a one-entry group.
- **Profile patch syntax.** Adding a new row needs `- insert:`; a bare `- id: …` only overrides an
  existing row and warns `entry "…" not found`.
- **Protocol verdict (measured).** ACP: DSH and OpenCode are both ACP **servers** → role collision;
  MCP: DSH is client-only, OpenCode is client-only (`client-mcp` is the inverse direction);
  DSH SDK/Typert vs OpenAPI: incompatible. **HTTP v2 is the chosen integration path.**
- **Orchestration fit.** DSH owns orchestration: `subagent` takes per-child `provider`/`model`/
  `reasoning_effort` (gated by `allowedModels`); `workflow` `agent()` fans out and bypasses the
  allowlist; `spawn_teammate` has **no** model parameter (inherits the Lead route). Adding HTTP
  routes to `allowedModels` is all that is needed for heterogeneous teams.
- **Measured HTTP facts to remember.** Global SSE stream (`/api/event`) must be demultiplexed by
  `data.sessionID`; `Session.Info.outcome` is sticky (wait on `session.execution.*`); no
  Last-Event-ID replay (recover via `/api/session/{id}/message`); `interrupt` keeps partial usage in
  session tokens but may not emit a final `step.ended`; model quota errors surface as 402
  (`opencode/glm-5.3-flash` currently fails with "Insufficient account funds").
- **Compaction owner.** Pick one per route: DSH `compaction-basic` (current PoC) or OpenCode
  `POST /api/session/{id}/compact`. Do not run both on one route.
- **Harness caveat.** Calling the host's `prepared.stream` wrapper a second time with a hand-built
  assistant message fails with `Cannot read properties of undefined (reading 'replayState')`;
  real loop messages carry the host envelope. Adapter `stream()` directly works — use direct calls
  in A/B scripts.
- OpenCode `client-mcp` (ticket-gated) is the only candidate for feeding DSH tools into OpenCode;
  a token request with a pairing code returned 403, so it remains **unconfirmed**.

## 7. Off-peak task — real-workload A/B, isolated environment

**Goal.** Decide whether `opencode-http-agent` can replace (or complement) `opencode-agent` for
real DSH sessions, by running the same real workloads through both routes in an isolated
`DSH_HOME` during off-peak hours and comparing correctness, latency, usage/cache accounting,
interrupt behaviour, and failure modes.

**Isolation (never touch live 3080 or `~/.dsh`).**

```bash
# Existing PoC home (already has the HTTP insert row and a clean bundle list):
#   /tmp/opencode/http-poc
# Rebuild if missing: copy ~/.dsh/profile template + add the insert row below.
DSH_HOME=/tmp/opencode/http-poc dsh --profile web --host 127.0.0.1 --port 39321 --no-open
# The boot log prints: dsh web: http://127.0.0.1:39321/?token=<token>
```

Profile patch row (must be `insert:`, not a bare id row):

```yaml
- insert:
    - id: dsh-opencode-v2-http
      name: '@nolit/dsh-opencode-v2/http'
      config:
        attachToDaemon: true      # reuse the CLI daemon from ~/.local/state/opencode/service.json
        spawnServer: true         # otherwise spawn `opencode serve --port 0`
        opencodePath: /home/minami/.bun/bin/opencode   # absolute: the host PATH has no ~/.bun/bin
        defaultModel: opencode/beam-free
        permissionDecision: once
```

**Preflight before any workload** (the 2026-10-29 failure): after booting the isolated profile,
confirm the HTTP route really serves models —

```bash
# catalog groups of the isolated instance (in-process probe, see
# /tmp/opencode/ocv2-measure/live-mirror-probe.mjs): expect 46 models under
# "OpenCode v2 (HTTP)"; a group with only "default" means the server was unreachable.
```

`allowedModels` must include the HTTP routes used by `subagent` (e.g.
`opencode-http-agent/opencode/beam-free`, `opencode-http-agent/opencode-go/deepseek-v4.1-flash`).
The isolated profile must NOT bundle `@quonaro/dsh-plugin-opencode`.

**Workload matrix (run each on both routes, same prompt, same cwd, same model id).**

| # | Workload | What it stresses | Success signals |
|---|---|---|---|
| W1 | 3-turn coding session with a tool call (edit+test) | session continuity, permission bridge, usage | identical final answer, turn-2 input ≪ CLI, no lost events |
| W2 | long-context turn (>150 KB prompt) | HTTP body vs argv limit | HTTP succeeds; CLI path already fixed via stdin (compare latency) |
| W3 | abort mid-generation (long essay) | interrupt | `OPENCODE_INTERRUPTED`, partial deltas preserved, no orphan child |
| W4 | Lead + 3 subagents on mixed routes (`subagent` tool with explicit `provider`/`model`) | per-child routing, allowlist | each child reports its own model; no cross-session bleed |
| W5 | `workflow` fan-out (2–3 agents, different models) | concurrency on one server | completes within `maxActiveSubagents`, SSE demux correct |

**Procedure.**

1. Off-peak only; confirm quota first: `curl -u opencode:<pw> http://127.0.0.1:49374/api/experimental/usage/limits`
   (avoid `opencode/glm-5.3-flash`; it returns 402).
2. Start the isolated profile (§7 isolation). Confirm zero activation warnings in the log.
3. For each W1–W5: run once on `opencode-agent`, once on `opencode-http-agent`, with a fresh DSH
   session id. Prefer driving the adapter directly
   (`/tmp/opencode/ocv2-measure/ab-http-vs-cli.mjs` is the template) for precise timings, then
   repeat W1/W4 through the booted isolated web app for end-to-end UI evidence.
4. Collect per turn: wall ms, first-token ms, chunk types, `usage{input,output,reasoning,cache.read,
   cache.write,cost}`, finish reason, plus the DSH session record
   (`~/.dsh/sessions/.../session.v4.jsonl.zstd` → decompress with `zstd -dc`).
5. Re-measure the live server's `/api/session/{id}/tokens` after each run for the authoritative
   totals; compare against the host-recorded `usage` chunk.
6. Record results in a new `dsh-opencode-v2/VERIFICATION.md` section or a dated measurement doc.

**Decision gates.**

| Gate | Rule |
|---|---|
| Correctness | same final answers on W1–W4; zero lost/duplicated deltas |
| Accounting | host `usage` equals OpenCode session `tokens` ± interrupt gap |
| Latency | HTTP first-token ≤ CLI on off-peak; no turn exceeds `timeoutMs` |
| Stability | 10 consecutive turns on one HTTP session with no 5xx, no SSE stall, no orphan `serve` |
| Isolation | live 3080 untouched; isolated home only; no writes to `~/.dsh` |

**Current baselines (single-run, 2026-10-29).** CLI: context 32,768 (discovery off), turn1
1,735 ms / first token 1,581 ms / input 2,541; turn2 1,002 ms / input 66. HTTP: context
1,048,576, turn1 2,152 ms / first token 946 ms / input 45; turn2 739 ms / input 2; abort 1.5 s →
`OPENCODE_INTERRUPTED`. Treat as directional, not final.

**Rollback.** The HTTP row is profile-level only: remove the insert row (or disable it) and restart

## 0.1 Why the sweep had to go (measured 2026-10-31)

The account quota counts **requests**, not tokens. `measureEntitlement()` sent one real completion per
catalog route → 49 requests per press. No cheaper truthful surface exists, all measured that day:

| Surface | Result |
|---|---|
| `GET {provider.settings.baseURL}/models` | 404 |
| `GET /api/model` | 49 rows, every one `status: "active"`, `enabled: true` |
| `opencode models` | the same 49 — static catalog, **not** entitlement (lists unusable routes too) |
| `GET /api/provider/opencode-go` | `models: 0` |
| OpenAPI document (130 paths) | only `/api/model`, `/api/model/default`, `/api/experimental/voice/models`, `/api/session/{id}/model` |
| `GET /api/experimental/usage/limits` | rolling/weekly/monthly **percent** only; 3 probes moved nothing |
| Console `…/activity/overview` | login wall — not opened |

What the catalog does give for free: the provider id **is** the plan. `opencode-go` 30 routes
(28 usable), `opencode` 19 routes (7 usable) — the same split the sweep had measured.

## 4. How the settings tab works now (0.7.2)

| Piece | Behaviour |
|---|---|
| Availability | plan = catalog provider id, zero requests; the other plan stays visible but disabled (`다른 플랜`) |
| Refusals | `observe()` records `unavailable` / `deprecated` / `auth` / `forbidden` from real turns; a served route clears a stale refusal; written only on change |
| Ordering | new route (first seen ≤ 7 days ago **and** not yet usage-ranked) → usage rank → name |
| New route | offered **first** in the prompt picker even when an allow-list is set, for the 7-day window; **the plan gate still applies** |
| Ranking | `opencode.ai/data/index.json`, one GET, cached **5 days** (`opencode-data-ranking.json`) |
| First-seen | `opencode-known-models.json`; the first run seeds the catalog at the epoch so nothing looks new |
| Picker | `activePlan ∩ enabledModels` **plus** any new route inside its window |
| Removed | `measureEntitlement`, `model-settings/measure`, the sweep button |

Owner decisions recorded: per-plan favourites are **not** wanted (checking a model is enough); nothing
is auto-enabled beyond the new-route window above.

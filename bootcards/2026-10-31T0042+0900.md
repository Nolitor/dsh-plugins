  `Personal` (oauth, active — this is the DSH web auth) and `OpenCode Go` (`opencode-go`, active).

- A direct curl to `https://opencode.ai/inference/go/openai/v1/chat/completions` returns **403
  `error code: 1010`** (Cloudflare bot gate), so that path cannot judge the credential at all.

**No credential was deleted.** Deleting an active, working credential is not what "delete the
revoked key" authorised. Nothing in the store was modified. If the owner still wants it removed,
that decision has to be re-stated against this measurement.

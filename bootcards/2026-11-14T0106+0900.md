## 1. Non-negotiable rules for this handoff

1. **Measure first.** Re-run the gates in §6 before assigning anything; a task whose premise is gone
   is marked done/dropped, not worked.
2. **Live state is the owner's.** No writes to `~/.dsh`, the live profile, sessions, or the running
   `dsh-web.service`; no restart. The two plaintext API keys and the EXAONE allowlist are owner state.
3. **No scheduler.** `spec:watch` is manual by design. Do not add cron/timer/background jobs.
4. **Secrets never leave the profile.** Do not print `apiKey:` values, do not copy them into docs,
   tests, fixtures, task notes or this card. P0-1 exists because the values were disclosed in a
   transcript.
5. **Single writer per scope.** Each task below owns disjoint files; the root integrates and reviews
   the final diff. Never let two workers edit `lib/client.src.js` or `lib/stream/` at once.
6. **No old phases.** Phase A/C/D/E, S4b/S4c, the legacy profile link removal, the five-place preset
   model and `markerDeltas` are closed; see ROADMAP-ARCHIVE.

**Model routing rules**

- **DeepSeek** — single-shot, well-scoped patches (T1, T7/T8 fallback).
- **MiniMax** — long-context/parallel work (T2, T3).
- **EXAONE** — cheap chores (T7/T8) **only after O2**. A child call currently fails with
  `child LLM route "exaone/k-exaone_v2.5" is not allowed for this Session`; do not bypass the
  allowlist, and do not silently substitute without recording it.
- **Hydrogen** — verification (T5) and code QA; **Argon** — design consistency; **Opus** — hard
  architecture (T4/T6). If a model route fails before producing output, retry with MiniMax and note
  it; do not leave a task ownerless.

## 5. Execution waves

1. **Wave 0 (owner):** O1 key rotation/migration; O2 allowlist; O3 hygiene scan after O1; O4 EXAONE top-level turn; decide S3/S4 (T9).
2. **Wave 1 (parallel, disjoint):** T1, T2, T3. Root adds package scripts/docs only after workers
   report; run `npm run verify` and the vendor suites.
3. **Wave 2:** T4 after T1/T2 are stable; T5 after the owner restart; T7/T8 as chores.
4. **Wave 3:** T6 only after Wave 2 proves the shared-path design; T9 only if the owner reopens it.

Do not start T4/T6 (both touch `lib/stream/` or `lib/client.src.js`) concurrently. T5 is read-only
and may run as soon as the restart is confirmed.
